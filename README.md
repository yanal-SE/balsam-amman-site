# Balsam Amman - Prototype

Next.js + Tailwind prototype for Balsam Amman Clinic.

This repo contains a simple multi-language MVP (Arabic/English) with a booking form and gallery placeholders.

Quick start:
1. npm install
2. npm run dev

Deploy to Vercel: connect this repository in Vercel and deploy (automatic on push to main).

Notes:
- Booking form is saved to a temporary Supabase endpoint in the demo instructions (configured after deploy).
- Live chat is disabled; WhatsApp button is used for patient contact.
